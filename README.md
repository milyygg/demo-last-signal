# Последний сигнал

Лендинг одного квеста с выбором даты, времени и количества участников. Учебный демо-проект: квест, контакты, расписание и цены вымышлены. Реальные бронирования не создаются, данные не отправляются, оплата не списывается.

**Посмотреть онлайн:** https://milyygg.github.io/demo-last-signal/

## Как скачать и открыть у себя

1. Нажмите зелёную кнопку **Code** вверху страницы репозитория, затем **Download ZIP**.
2. Распакуйте архив.
3. Откройте файл `index.html` в браузере. Сборка не требуется, изображения и шрифты хранятся локально.

## Что внутри

- `index.html` - страница квеста
- `style.css` - адаптивные стили
- `script.js` - календарь, выбор сеанса и демонстрационный расчёт стоимости
- `fonts.css`, `fonts/` - локальные шрифты Manrope
- `assets/` - изображения

Технологии: HTML, CSS, JavaScript.
